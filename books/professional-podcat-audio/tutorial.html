    Listen fairly

    A small listening laboratory

    Use the same script, position and recording path. Change one variable at a time. Keep raw originals; loudness-match audition copies before judging tone.

    A practical test sequence for both microphones
    1. Clean reference: cardioid, 20 cm, compression bypassed, software effects off. Record three takes for each mic.
    2. Placement: compare 15 / 20 / 30 cm, then 0° / 15° / 30° off axis. Return to your reference after each change.
    3. Voicing: Twin87 Vintage / Modern with settling and gain recalibration. B67 internal profile tests only after manufacturer access instructions are confirmed; an as-found baseline is complete without opening the mic.
    4. Filters: compare off with one high-pass location at a time. PRE-73 PREMIER is 80 / off / 200 Hz. Try pad only to answer an overload question.
    5. Compression: ratio 1.5 / 2 / 3 / 4 / 6; attack 0.5 / 1 / 2 / 3 / 6 / 12 / 25 / 50 ms; recovery 25 / 50 / 100 / 400 / 800 ms / 1.5 s / Auto 1 / Auto 2; detector off / 50 / 100 Hz / 7 kHz. Sweep one control and return to baseline.
    6. Two compressor tests: keep threshold fixed to learn what a knob does; separately adjust threshold to the same observed reduction to compare character. Label which method you used.
    7. Finished chain: pick the best repeatable setup for each mic and compare at the same delivery loudness. Do not attribute every processed difference to the mic alone.
    The spoken test script

    Welcome to Professional Podcat Audio. Today we are comparing a calm voice, a clear explanation and a brighter announcement. Peter packed a paper parcel. Six soft sentences should stay smooth. Now I will speak quietly, then return to my usual level. This next sentence is more excited, but I will keep the same distance. One, two, three. And now, ten seconds of room tone.
