Bespoke Learning

This project follows Alexy Khrabrov's approach from Learn Rust from Bespoke Books: create a book around the learner's real tools, references, and next practice session.

The result is not a generic course. It is a living textbook aligned to a particular rig, taste, and learning path.

Current Focus

The interactive tutorials stay GarageBand-only. The larger manual also includes scalable subsections for GarageBand, Ableton Live, and FL Studio so new DAWs can be added without breaking table layouts.
