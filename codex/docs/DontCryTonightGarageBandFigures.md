# Don't Cry Tonight John E.S Remix: Figure-by-Figure MPK Mini IV and GarageBand Settings

Reference video: Savage & John.E.S, "Don t cry tonight (The official remix)"  
<https://www.youtube.com/watch?v=zuHLHvZv4Ac>

This guide translates the official remix feel into a legal practice project on
Akai MPK mini IV and GarageBand. Build your own version with a sung guide
phrase, a lead-synth stand-in, or cleared vocal material.

Use the John E.S video for mood, arrangement, and video pacing. Use MPK-centric
cover videos for controller behavior: visible pad hits, mini-key hooks, and
clear desk-shot proof that the arrangement is playable.

## Figure 1 - Project and Tempo

GarageBand setting:

- New Project > Empty Project.
- Tempo: 116-122 BPM starting range.
- Time signature: 4/4.
- Metronome: on while recording.
- Count-in: on.
- Cycle area: 8 or 16 bars while building loops.

MPK setting:

- Connect over USB-C.
- Use default program first.
- Arp and Note Repeat off for initial recording.

Check:

- A software instrument track should respond to MPK keys before you build the
  full template.

## Figure 2 - Track Template

GarageBand tracks:

| Track | Patch family | Purpose |
|---|---|---|
| Kick | Electronic kit | Four-on-the-floor pulse. |
| Snare/Clap | Electronic kit | Backbeat. |
| Hats | Electronic kit | Motion and lift. |
| Italo Bass | Synth Bass | Octave groove. |
| Chords | Analog Pad or Synth Strings | Emotional bed. |
| Lead Hook | Bright Synth Lead | Answer melody. |
| Vocal Guide | Audio | Your own phrase or cleared source. |
| FX | Synth/effect | Risers, delay, reverb throws. |

Check:

- Name tracks exactly. The tutorial works better when the timeline is readable.

## Figure 3 - MPK Pad and Section Map

| MPK control | Sound or cue | Use |
|---|---|---|
| Pad A1 | Kick | Beats 1, 2, 3, 4. |
| Pad A2 | Clap/snare | Beats 2 and 4. |
| Pad A3 | Closed hat | Eighth notes. |
| Pad A4 | Open hat | Last eighth before section changes. |
| Pad A5 | Crash | Chorus entry. |
| Pad A6 | Tom/gated fill | End of 8-bar sections. |
| Pad A7 | Riser/noise | Pre-chorus lift. |
| Pad A8 | Stop/accent | Ending. |
| Pad B1 | Chorus cue | Visual cue when chorus region starts. |
| Pad B2 | Break cue | Visual cue when kick drops out. |
| Pad B3 | Delay cue | Visual cue for delay throw automation. |
| Pad B4 | Final tag cue | Visual cue for last section. |

GarageBand setting:

- Select an electronic kit.
- Record kick, clap, and hats as separate passes if possible.
- Quantize kick/clap tightly; keep hats a little more human.

Check:

- Mute every track except drums. The groove should already feel like a dance
  record.
- On camera, the viewer should understand pads A1-A4 as the drum zone and the
  higher pads as section/FX cues.

## Figure 4 - Italo Bass

MPK setting:

- Use Octave Down.
- Play lower keys with short, even notes.
- Keep pitch bend off until the main line works.

GarageBand setting:

- Select a Synth Bass patch.
- Start with a two-bar region.
- Duplicate it across intro, groove, chorus, and final tag.

Beginner bass shape:

| Count | Move |
|---|---|
| 1 | Root. |
| and | Octave. |
| 2 | Root or fifth. |
| 3 | Root. |
| 4 and | Passing note. |

Check:

- The bass and kick should feel like one machine.

## Figure 5 - Chords and Pad

MPK setting:

- Use middle octave.
- Play simple minor and major triads.
- Use mod wheel only for a gentle brightness lift.

GarageBand setting:

- Patch: Analog Pad, Synth Strings, or Classic Synth.
- Track volume starts low.
- Add reverb after the chord rhythm works.

Check:

- The pad should make the chorus wider without hiding the vocal/lead.

## Figure 6 - Lead or Vocal Stand-In

Options:

| Source | Best use |
|---|---|
| Your own voice | Most honest practice version. |
| Lead synth | Good for learning without singing. |
| Cleared vocal loop | Best polished demo path. |
| Original vocal | Private study only unless you have rights. |

GarageBand setting:

- For voice: create Audio track, set input, record dry.
- For lead: create Software Instrument track with bright lead synth.
- Add delay throws only at phrase endings.

Check:

- The song still makes sense when you mute the pad and FX tracks.

## Figure 7 - Smart Controls

Suggested controls:

| Control | Use |
|---|---|
| K1 or Smart Control 1 | Bass level. |
| K2 or Smart Control 2 | Pad filter cutoff. |
| K3 or Smart Control 3 | Reverb amount. |
| K4 or Smart Control 4 | Delay amount. |
| K5 | Lead brightness. |
| K6 | FX/riser level. |
| K7 | Chorus pad level. |
| K8 | Master performance macro if available. |

GarageBand note:

- GarageBand Smart Controls are useful, but MIDI mapping is limited compared
  with Logic Pro. Use the mouse for any parameter the MPK cannot control.

Check:

- Record one obvious filter opening into the chorus. Do not automate everything.

## Figure 7A - MPK-Centric Control References

Borrow these control ideas from MPK cover videos:

| Reference type | Control lesson |
|---|---|
| MPK/GarageBand desk cover | Keep the camera close enough to show both pads and keys. |
| MPK synthwave live-loop cover | Use lower keys for bass, upper keys for hook, pads for drums. |
| 1980s MPK cover | Make the lead phrase visible; the hook is the star. |
| Modern 1980s-style MPK cover | Keep drum pads simple and use filter/FX moves for the drop. |

Apply those lessons to the John E.S arrangement:

- Film Pad A1 kick hits during the groove entrance.
- Film lower keys for the Italo bass.
- Film upper keys for the lead or vocal stand-in.
- Film K2/K4 or Smart Controls during filter and delay moments.
- Cut back to the John E.S-inspired montage idea only after the control action
  is clear.

## Figure 8 - 64-Bar Region Layout

| Bars | Regions active |
|---|---|
| 1-8 | Kick, hat, filtered pad. |
| 9-16 | Kick, clap, hat, bass. |
| 17-24 | Bass, restrained drums, vocal/lead. |
| 25-32 | Add pad width, riser, open hat. |
| 33-48 | Full chorus: drums, bass, chords, lead/vocal, FX. |
| 49-56 | Break: pad and vocal/lead, reduced drums. |
| 57-64 | Final chorus/tag and ending hit. |

Check:

- Duplicate regions rather than re-recording every section. Then edit the few
  moments that need variation.

## Figure 9 - Video Shot List

Shot plan:

- Red/blue light or simple color backdrop for intro mood.
- MPK top-down for drums and bass.
- GarageBand timeline for the section layout.
- Keyboard close-up for lead hook.
- Vocal or face/performance shot for emotional focus.
- Wide desk shot for final chorus.
- Text outro with title and credit.

Check:

- Sync to exported GarageBand audio, not camera audio.
- Use the original video's montage grammar, but replace its stage footage with
  your own MPK, GarageBand, vocal, and lighting shots.

## Figure 10 - Final Checklist

- Tempo chosen.
- Tracks named.
- Drum pads mapped by habit.
- Bass line loops cleanly.
- Chords support the vocal/lead.
- One riser or filter move into chorus.
- Exported audio does not clip.
- Video includes MPK, GarageBand, and performance context.

Beginner success is a 60-90 second practice edit, not a full 5:47 official
remix.
