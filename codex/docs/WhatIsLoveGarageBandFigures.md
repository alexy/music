# What Is Love Live Loop: Figure-by-Figure MPK Mini IV and GarageBand Settings

Reference video: MunomaMusic, "Haddaway - What Is Love (Live Loop Cover) | Minilab 3"  
<https://www.youtube.com/watch?v=wK1V8v1UPZo>

This guide recreates the workflow on Akai MPK mini IV and GarageBand. It does
not copy the original Ableton/Minilab setup. Use it as a visual checklist while
building your own GarageBand project.

## Figure 1 - Hardware and Project Start

MPK setting:

- Connect MPK mini IV directly to the Mac over USB-C.
- Use the default program first. Do not edit pad notes until GarageBand hears
  keys and pads correctly.
- Keep arpeggiator and note repeat off for the first test.

GarageBand setting:

- New Project > Empty Project.
- Track type: Software Instrument.
- Tempo: 124 BPM starting point.
- Key: minor, chosen by ear.
- Metronome: on.
- Count-in: on.

Check:

- Play the MPK keys. GarageBand should produce sound from the selected software
  instrument.
- Press pads. You should see MIDI activity and hear drum sounds when a drum kit
  track is selected.

## Figure 2 - Main Track List

GarageBand tracks:

| Track | Patch family | Region length | Purpose |
|---|---|---:|---|
| Drums | Electronic kit | 2 bars | Four-on-the-floor groove. |
| Bass | Synth Bass | 2 or 4 bars | Root/fifth/octave motion. |
| Chords | Classic Synth or Pad | 4 bars | Wide harmonic bed. |
| Hook | Lead Synth | 2 or 4 bars | Recognizable answer phrase. |
| FX | Synth or audio effect track | 4 or 8 bars | Filter, reverb, delay, riser. |

MPK setting:

- Pads control the selected drum track.
- Keys control whichever software instrument track is selected.
- Use Octave Down for bass and Octave Up for hook if needed.

Check:

- Name tracks before recording. The screen should read like a tutorial:
  `Drums`, `Bass`, `Chords`, `Hook`, `FX`.

## Figure 3 - Pad Map for Drums

MPK pad map:

| Pad | Drum sound | Pattern job |
|---|---|---|
| 1 | Kick | Beats 1, 2, 3, 4. |
| 2 | Clap or snare | Beats 2 and 4. |
| 3 | Closed hat | Offbeats or eighth notes. |
| 4 | Open hat | Last eighth before a new section. |
| 5 | Crash | First beat of the full loop. |
| 6 | Percussion hit | Fill at bar endings. |
| 7 | Riser/noise | Build into the final section. |
| 8 | Stop/accent | Ending hit. |

GarageBand setting:

- Select the Drums track.
- Choose an electronic kit.
- Record a two-bar region.
- Quantize to 1/8 or 1/16 only if the groove needs it.

Check:

- The beat should work with only pads 1, 2, and 3 before you add fills.

## Figure 4 - Bass Track

MPK setting:

- Press Octave Down if the bass is too high.
- Play short notes with steady velocity.
- Use pitch wheel only for a deliberate end-of-phrase bend.

GarageBand setting:

- Select Bass track.
- Choose a synth bass patch.
- Record a two-bar or four-bar loop.
- Edit obvious wrong notes in the Piano Roll.

Pattern:

| Beat | Bass idea |
|---|---|
| 1 | Root note. |
| 2 | Root or fifth. |
| 3 | Octave or fifth. |
| 4 | Passing note back to root. |

Check:

- The bass should make the kick feel stronger. If it fights the kick, simplify.

## Figure 5 - Chords and Pad Width

MPK setting:

- Return to middle octave.
- Use two or three fingers, not full piano voicings.
- Keep chord stabs shorter for dance energy or longer for a pad bed.

GarageBand setting:

- Select Chords track.
- Choose Classic Synth, Analog Pad, or Bright Pad.
- Lower track volume before recording; pads get big quickly.
- Add light reverb only after the part works dry.

Check:

- Mute the hook track and listen. The chords should support the bass, not become
  the main melody.

## Figure 6 - Hook or Lead Phrase

MPK setting:

- Press Octave Up if the lead sits too low.
- Use the mod wheel lightly for vibrato or brightness.
- Record slowly first, then tighten timing.

GarageBand setting:

- Select Hook track.
- Choose a bright synth lead.
- Record several short takes.
- Keep the best two-bar phrase.

Check:

- The hook should be memorable even with drums muted. If it needs every other
  track to make sense, it is not strong enough yet.

## Figure 7 - Smart Controls and Knob Translation

MPK setting:

- Try the eight knobs against GarageBand Smart Controls.
- If a knob moves a useful Smart Control, keep it.
- If not, use the mouse for Smart Controls and save deep MIDI mapping for Logic.

GarageBand setting:

- Press `B` to show Smart Controls.
- Use filter cutoff, tone, reverb, and delay as the first four performance
  controls.
- Record automation only after notes are stable.

Recommended control map:

| Control | Sound move |
|---|---|
| K1 or Smart Control 1 | Drum or bass level. |
| K2 or Smart Control 2 | Filter cutoff. |
| K3 or Smart Control 3 | Reverb amount. |
| K4 or Smart Control 4 | Delay or echo amount. |

Check:

- One clear filter opening is better than constant knob motion.

## Figure 8 - Region Layout

GarageBand setting:

- Loop each recorded region.
- Trim region edges cleanly.
- Arrange the build left to right:
  `intro`, `drums`, `bass`, `chords`, `hook`, `full`.

Suggested timeline:

| Bars | Active regions |
|---|---|
| 1-4 | Hook or chords only. |
| 5-8 | Drums enter. |
| 9-16 | Bass enters. |
| 17-24 | Chords widen. |
| 25-32 | Hook plus full drums. |

Check:

- Solo each region once. Every part should loop without clicks or dead space.

## Figure 9 - Camera Plan

Video settings:

- Main shot: top-down over the MPK.
- Insert shot: GarageBand track list and regions.
- Final shot: angled desk view with both hands visible.
- Sync anchor: a visible pad hit or key hit on beat 1.

GarageBand export:

- Share > Export Song to Disk.
- WAV or AIFF for the video editor.
- Watch the exported file before editing.

Check:

- The first five seconds must show what is being built: hands, controller, and
  the musical premise.

## Figure 10 - Final Performance Checklist

Before recording the final take:

- MPK connected directly.
- GarageBand tempo set.
- All tracks named.
- Metronome and count-in set as needed.
- Drums, bass, chords, hook, and FX regions loop cleanly.
- Exported audio is not clipping.
- Camera sees pads and keys.
- You have a sync anchor.

Successful beginner result:

- A 30-60 second arrangement.
- Five or fewer musical layers.
- One obvious build.
- One visible MPK performance angle.
- One clean GarageBand export.
