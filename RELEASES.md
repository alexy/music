# Release Names: Italo-Disco Stars

Releases of this repository are named after Italo-disco and Italian pop stars,
in honor of the music these manuals teach you to remix. The roster, in planned
order:

| Release name | Used by | Notes |
|---|---|---|
| Savage | apc40-mk2-ableton-start 0.2.0 (2026-07-06) | Of course: the Don't Cry Tonight book release. |
| Ricchi e Poveri | — | |
| Al Bano and Romina Power | — | |
| Pupo | — | |
| Toto Cutugno | — | |
| Adriano Celentano | — | |

Add new stars to the bottom of the roster as needed. A release name is used
once; the "Used by" column records the book/version and date it shipped with.

Artifacts in each release carry the unified publishing version stamp
`<version>-<short-git-hash>` (see `codex/docs/books/*/PUBLISH.md`), so every
released file traces back to the exact source commit it was built from.
